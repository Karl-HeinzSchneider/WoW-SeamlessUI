# Specialization icons

These 128 × 128 TGA files were copied unchanged from the user-supplied
**Clean Icons - Mechagnome Edition** pack (`ICONS/`). Only specialization-related
artwork and classic talent-tree variants are included.

`src/icons.lua` resolves the original Blizzard icon paths to client file IDs and
substitutes these files only when rendering specialization icons in Seamless's
meter and analysis rows. Unknown icons retain their original client texture.

The artwork is third-party material, separate from Seamless's MIT-licensed code.
No license or attribution file accompanied the supplied pack.

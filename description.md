# SeamlessUI

Simple and modular improvement of the default UI for WoW Forever

As the original creator of [DragonflightUI classic](https://www.curseforge.com/wow/addons/dragonflight-ui-classic) I want to bring the same feel of a complete UI overhaul in the spirit of a Blizzard UI, but with more customization, more quality of life and defaults that just feel right.

If you want to be part of that, feel free to leave a comment and suggest anything or report any issue you might encounter; I will do my best to find a good solution for everything.

## Features

- Keeping the overall style of the default UI, but improving all those small things
- Modular: only use the sub addons you actually need, with every feature configureable through the options

## Modules

- Core: needed for every sub module, but also has some general tweaks
- Castbar: more settings, moveable
- Chat: basic chat improvements like copy or history
- DamageMeter: simple damagemeter with details-like controls; also threat meter
- Darkmode: darkmode on every frame (WIP)
- Tooltip: visual overhaul for background/border, extended UnitTooltip (visibility, classcolor, better guildinfo etc), extended SpellTooltip (can show Spell/Icon IDs etc); also better Tooltip position (e.g. on mousecursor)
- UI: more features on default frames, greatly improved editmode
- Unitframes: toggle for Unitframestyle (early default Forever vs new style from build #70425 - 16.10.2026 onwards), class/reaction colored healthbars, show thread on target frame
